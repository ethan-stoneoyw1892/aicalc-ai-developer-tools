## What is aicalc?

aicalc combines practical AI and web-development helpers in a single browser application. The toolkit covers LLM cost planning, token measurement, generation tasks, and security checks, allowing developers to handle several routine activities without jumping between separate services.

The project is intended for developers, prompt writers, and technical groups working with LLM content and web application configuration. Because the tools run through a browser-first client-side workflow, they provide convenient access to calculations, text processing, and lightweight validation from one interface.

## Included Tools

- Estimate LLM spending with the AI pricing and cost calculator
- Count tokens to inspect prompts and other model inputs
- Create cron expressions for scheduled processes
- Generate CSP headers for web security settings
- Remove or redact PII from sensitive text
- Detect commonly exposed secrets in environment-related content
- Review dependencies for vulnerability indicators
- Use client-side browser utilities for quick local workflows
